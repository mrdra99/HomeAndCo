# Loghi dei brand

SVG (preferito) o PNG trasparente, altezza 120 px, sfondo trasparente, preferibilmente monocromatici.

I file qui sono referenziati dai JSON in `content/` con percorso `/uploads/brands/<file>`.
Cartella usabile come `media_folder` di Decap CMS (`public_folder: /uploads/brands`).
Testo alternativo (alt) obbligatorio nel contenuto.
